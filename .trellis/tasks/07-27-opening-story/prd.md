# 开场剧情

## Goal

基于《斗萝大陆_开局剧情设计_V2.0》，生成可直接用于剧情、镜头、动画、音频和程序协作的开场分场脚本。

首个独立验收里程碑为 `S0 冷开场：月痕`：在 1–2 分钟内建立露娜负伤、微光森林异变、断月纹追踪和古树月牙刻痕响应，并以村钟转入 `S1 抵达晨曦村`。

后续在同一任务内按用户指令逐场推进 `S1–S7`，但本轮不提前扩写。

## Background

- 剧情事实与版本取舍以 `doc/剧情设计/开局/斗萝大陆_开局剧情设计_V2.0.docx` 为唯一内容基准。
- `斗萝大陆_开局剧情设计_V3.1_开局60分钟逐镜头商业级脚本.docx` 仅可参考表达粒度，不得覆盖 V2.0 的剧情事实。
- V2.0 已定义 S0 的场景目标、建议时长、触发条件、核心画面、露娜关键对白和结尾字幕。
- 分场脚本是制作执行稿，需要让叙事、镜头、动画、音频和程序人员能够据此拆解工作。

## Requirements

### R1. 总体范围

- 本任务覆盖 V2.0 的 `S0–S7` 分场脚本，按场次逐个产出和验收。
- 当前里程碑只生成 `S0 冷开场：月痕`。
- 不改写 V2.0 已确认的世界观、角色动机、奖励、任务链和信息释放顺序。

### R2. S0 内容不变量

- 场景位于微光森林深处，时间发生在玩家抵达晨曦村的同一时段。
- 雾逆着树梢风向向古树聚拢。
- 实体露娜肩侧负伤、行动失衡，但仍挡在古树与狼族领地之间。
- 露娜确认异常不是野兽所为，断月纹仍在追踪她，并判断有人向森林埋入异物。
- 古树根部出现残缺月牙刻痕；露娜旧伤渗出银色雾光并与刻痕发生响应。
- 白光后切黑，以村钟第一声和“同一时刻，晨曦村东侧村道”转入 S1。

### R3. 制作执行信息

- 明确场次、场景、时间、建议时长、触发条件、角色和可跳过规则。
- 使用逐镜头结构描述镜号、时长、景别/机位、画面与表演、对白/字幕、声音/转场。
- 补充必要的角色表演原则、音画执行要点、跳过落点和场次验收项。
- 对 V2.0 未规定的镜头细节只做不改变剧情含义的最小扩写。

### R4. 信息边界

- S0 不解释源萝之力、幕后污染者或月痕完整机制。
- S0 不承载任务目标、战斗教学、奖励或其他关键操作信息。
- 不把露娜演成等待救援的弱者；伤势体现代价，守护与判断仍是角色主导行为。
- 不提前引入 V2.0 未确认的幼崽、雾兽实体、空白卡匣或契约设定。

### R5. 交付形式

- 交付独立 DOCX，存放于 `doc/剧情设计/开局/`。
- 文件名应清楚包含“分场脚本”“S0”“冷开场”“月痕”和版本号。
- 文档需完成 DOCX 渲染和逐页视觉检查；若本地渲染依赖不可用，必须明确报告未完成的视觉验证。

### R6. S0 视频接入

- S0 成片存放于 `game-client/public/assets/generated/videos/opening/s0-moon-trace.mp4`，源素材保留在 `game-client/art-source/generated/videos/opening/`。
- 玩家处于 `arrival` 阶段时全屏播放 S0，视频自然结束后沿用现有 `start` 流程进入 S1。
- 播放 3 秒后允许跳过；结束与跳过必须幂等，不能重复提交开场状态。
- 优先尝试有声自动播放；若浏览器阻止，则显示明确的播放按钮，不静默播放。
- 视频加载失败时回退到原序章面板，不能形成黑屏或阻断开局。

### R7. S0 后的首个任务交互

- S0 播放结束进入晨曦村后，左侧任务追踪栏暂不显示，并提示玩家先与晨曦村村长对话。
- 村长完成开场对白后，通过单一剧情按钮一次性交付“村道补给”“林缘踏查”“实战准备”三项任务。
- 三项任务只能在村长剧情交付后激活；重复提交不得创建重复任务进度。
- 领取成功后显示包含三个任务名的获取提示，并恢复左侧任务追踪栏。

## Acceptance Criteria

- [x] AC1：S0 默认演出时长约 90 秒，且可在 60–120 秒内调整。
- [x] AC2：逐镜头脚本完整覆盖 V2.0 的 S0 核心动作、三句关键对白、白光切黑、村钟和结尾字幕。
- [x] AC3：观众无需额外说明即可识别露娜负伤、雾流反常、古树刻痕异常和未知威胁仍未现身。
- [x] AC4：露娜的行为持续体现警觉、判断和守护责任，没有无目的摆拍、卖萌或求救化表达。
- [x] AC5：未提前泄露源萝之力、幕后者、完整月痕机制、任务目标、奖励或战斗教学。
- [x] AC6：跳过 S0 后可直接进入 S1，且不会丢失操作所需信息或触发重复状态结算。
- [x] AC7：DOCX 无文字裁切、表格溢出、缺字、重叠或明显分页缺陷。
- [ ] AC8：文档内容与 V2.0 对照检查通过；V3.1 仅影响格式粒度，不引入其新增剧情。
- [x] AC9：S0 视频可通过静态资源路径访问，并进入生产构建产物。
- [x] AC10：组件具备有声自动播放尝试、手动播放回退、3 秒后跳过、自然结束进入 S1 和加载失败回退。
- [x] AC11：视频结束与跳过共享单次提交保护，加载中或已离场时不会重复触发 `start`。
- [x] AC12：S0 结束后开场阶段为 `meet_chief`，三项任务均保持 `not_started`。

- [x] AC14：仅晨曦村村长可一次性交付三项任务，重复领取保持幂等且不产生重复记录。
- [x] AC15：领取成功后显示三个任务名，阶段进入 `prepare`，左侧任务追踪栏恢复。

## Out of Scope

- 本轮不生成 S1–S7 的具体脚本。
- 除用户后续明确要求的 S0 视频播放接入与首个村长任务交互外，不修改后续场次实现。
- 不制作分镜图、角色立绘、配音成品、动画或游戏内演出。
- 不重写或升级《开局剧情设计 V2.0》。

## Key Decisions

- 内容权威版本：V2.0。
- 当前最小交付：只完成 S0。
- 脚本粒度：制作执行级逐镜头脚本，而非剧情梗概。
- 场次长度：沿用 V2.0 的 1–2 分钟约束，默认按约 90 秒设计。
- 文档格式：独立 DOCX，并进行渲染视觉 QA。

## Risks and Deferred Items

- 后续 S1–S7 的场内互动粒度、玩家选项写法和技术字段可在推进到对应场次时分别确认。
- S0 的具体美术资产、镜头系统能力和音频预算尚未纳入实现约束；当前脚本使用可降级的镜头语言，并将“风向与雾向相反”列为不可丢失的视觉机制。

## Milestone Status

- `S0 冷开场：月痕`：已产出分场脚本、缺失贴图提示词、对白/环境/音效/配乐提示词和逐镜头视频提示词，并通过 5 页 DOCX 渲染视觉检查；内容复核待同步修订“突然中断的狼族足迹”“银光血使苔藓熄灭”两处非 V2.0 S0 信息，以及 DOCX 与 Markdown 的抠图背景规格冲突。
- `S1–S7`：待后续逐场推进。

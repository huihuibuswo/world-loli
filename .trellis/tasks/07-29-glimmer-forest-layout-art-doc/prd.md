# 微光森林地图与贴图优化文档

## Goal

基于开场剧情、S0 冷开场贴图与视频提示词、现有游戏地图实现和现有美术资产，产出一份可直接指导微光森林地图重构、贴图生成、场景组装与验收的 Markdown 规范，使玩家进入可玩地图后看到的森林延续开场演出的视觉身份，而不是复用晨曦村的明亮草地与道路风格。

## Background

- 剧情权威基准为 `.trellis/tasks/07-27-opening-story/prd.md` 记录的《斗萝大陆_开局剧情设计_V2.0》内容不变量。
- 视觉执行参考为 `doc/剧情设计/开局/S0_冷开场_月痕_缺失贴图生成提示词.md` 和现有 `opening-s0-*` 资产。
- 当前 `WorldScene.ts` 中森林与村庄共用 `grass-ground`、`dirt-path` 和同一套路网，只额外增加绿色蒙层。
- 当前森林以同一张明亮圆冠 `ancient-forest-tree` 重复铺设，缺少开场画面中的幽深层次、逆流雾、根系地貌和断月异常视觉。
- 当前森林地图承载传送、NPC、植物采集、三处剧情证据、露娜战斗和返回村庄等既有玩法，视觉优化不能破坏这些功能锚点。

## Requirements

### R1. 演出视觉不变量

- 微光森林整体为黄昏将尽的冷青蓝、深绿和少量冷白微光，不使用晨曦村式暖黄高亮地表作为主视觉。
- 树冠或落叶的顺风方向与贴地银蓝雾的逆流方向必须能同时被识别。
- 核心古树、盘根地形、残缺月牙刻痕和银雾汇聚构成森林的标志性视觉中心。
- 森林应神秘、压迫但不恐怖；未知威胁通过环境异常表达，不直接铺设怪物或血腥元素。
- 断月纹保持残缺、冷白、非完整法阵，不能变成常规发光装饰。

### R2. 地图结构

- 文档需定义入口缓冲区、林间主径、采集支路、雾区边缘、月光空地、古树月痕区、遗迹隐蔽区和回村出口等功能分区。
- 主路线应让首次进入的玩家自然到达森林向导、剧情证据和露娜所在的月光空地，同时保留探索支路。
- 地图布局需兼容现有约 `2048 x 2048` 世界边界及既有传送、NPC、植物和证据节点语义；坐标可给建议值，但本轮不修改服务端数据。
- 道路不使用连续铺满的村庄黄土路，应改为被根系、苔藓、湿土和雾线打断的林间可读路径。
- 核心演出区需预留角色站位、镜头取景、交互提示和战斗触发空间，避免树冠或前景雾遮挡角色。

### R3. 贴图与场景层级

- 文档需覆盖地表、道路、树木、根系、石块、树桩、灌木、菌类、月光植物、雾层、微光粒子、断月刻痕、遗迹和前景遮罩等资产类别。
- 每类资产需说明用途、建议尺寸或切片方式、透明背景要求、色彩与明度范围、碰撞建议、层级和必要变体数量。
- 明确现有资产的“保留”“调色后复用”“降级为普通装饰”“重做”结论，重点处理 `grass-ground.webp`、`dirt-path.webp`、`ancient-forest-tree.png`、`forest-obstacle.png`、`forest-stump.png` 与 `opening-s0-*`。
- 避免用一张古树贴图重复充当整片森林；核心古树与普通乔木必须在轮廓、尺度、色温和叙事功能上区分。
- 动态效果应拆为可循环、可分层、可降级的雾与粒子层，静态地图在关闭动画时仍保持可读。

### R4. 生成提示词

- 文档需提供统一风格母提示词、统一负面提示词和各关键资产的独立生成提示词。
- 提示词必须锁定俯视或 3/4 俯视游戏地图视角、二次元奇幻 RPG 质感、透明或指定纯色背景规则，并禁止正视 CG 构图混入地图贴图。
- 提示词需覆盖至少：森林地表、湿土林径、普通乔木变体、核心古树、盘根障碍、雾层、断月刻痕、月光空地和遗迹组件。
- 对需无缝平铺、透明抠图或可循环动画的资产分别写明输出约束。

### R5. 可玩性与技术约束

- 角色、NPC、采集物、证据节点和交互提示在冷色背景上必须保持清晰轮廓。
- 视觉碰撞范围应贴合树干、石块和根系脚部，不以整张透明画布作为阻挡范围。
- 前景遮挡物需支持角色经过时降透明或保证关键交互区不被遮住。
- 雾和粒子不得覆盖小地图、UI 或制造虚假可通行区域；高浓度雾只用于边界、叙事节点和路径引导。
- 文档需给出性能预算建议，限制全屏叠层、同屏透明大图和高频粒子数量。

### R6. 交付形式

- 正式交付文件为 `doc/剧情设计/开局/微光森林地图与内部贴图优化规范_V1.0.md`。
- 文档需包含：目标与视觉锚点、现状问题、地图布局、场景分区、贴图清单、生成提示词、组装规则、验收清单、实施优先级和延期项。
- 使用 Markdown 表格和文本示意图表达精确映射；不要求本轮生成图片、修改代码或调整服务端坐标。

## Acceptance Criteria

- [x] AC1：文档明确引用开场剧情的雾向、古树、断月刻痕、冷青黄昏和未知威胁等视觉不变量。
- [x] AC2：文档提供完整地图分区与主路线示意，并标明入口、森林向导、五类采集点、三处证据语义、露娜/月光空地和回村出口的布局原则。
- [x] AC3：文档至少列出 12 类地图或特效资产，并为每类给出用途、规格、层级、碰撞或动画要求。
- [x] AC4：现有关键资产均有明确处置结论，且不会继续把核心古树同图重复铺满整个森林。
- [x] AC5：至少提供 9 组可直接使用的关键资产生成提示词，以及统一风格和负面提示词。
- [x] AC6：规范同时覆盖剧情演出连续性、移动与交互可读性、碰撞、遮挡、性能和静态降级。
- [x] AC7：文档明确 Must / Should / Defer，Must 范围足以形成首版可玩的演出一致森林，不把本轮扩大为实际美术生产或代码改造。
- [x] AC8：Markdown 结构、表格、代码块和文本示意图检查通过，无断链、占位符或相互矛盾的背景要求。

## Out of Scope

- 不修改 `WorldScene.ts`、预加载逻辑、服务端地图数据、NPC 或剧情状态。
- 不实际生成、抠图、压缩或导入任何美术资产。
- 不重做开场视频或修改《开局剧情设计 V2.0》的剧情事实。
- 不设计微光森林之外的晨曦村、战斗场景或后续区域。
- 不在本轮确定最终像素坐标、碰撞数值或运行时粒子参数。

## Key Decisions

- 正式文档服务于后续美术制作和地图实现，细度为“可执行规范”，不是概念草案。
- 地图继续采用现有俯视探索玩法，开场 CG 只提供色彩、气氛、标志物和异常机制，不直接作为地图背景铺设。
- 最小可靠方案优先重做地表、林径、普通树群与核心古树层级，并复用开场雾与月痕的视觉语言。
- 本轮只产出一个 Markdown 文档，不拆分子任务。

## Risks and Deferred Items

- 现有 `opening-s0-*` 资产是横屏演出素材，直接用于俯视地图可能视角冲突；文档只允许作为风格参考或拆分后的特效参考。
- 具体坐标与碰撞需要在实际实现阶段结合地图截图和移动测试二次校准。
- 动态雾的性能上限需要实现后在目标设备实测，本轮只给保守预算。

# 微光森林部分2：银雾溪谷全量贴图布局与河流通行优化方案 V1.0

## 1. 结论

部分2的核心体验应收束为：玩家从西南入口沿溪谷前进，所有地表、道路、水体、岸线、植物、桥梁、特效和出入口围绕同一条动线重新布局；河流始终是不可直接穿越的地形边界，只能通过两座明确可见的倒木桥到达对岸。

本次优化不重新生成整套美术，优先复用现有 V2 资产并重建布局与碰撞。最小可靠方案如下：

1. 三张地表变体、宏观遮罩、两条道路均重新定义用途，不再整图同相位叠加或各自独立穿插。
2. 删除单张 `2100 x 260` 旋转水带的权威布局，改为沿溪流中心线铺设 7 段透明水流带。
3. 十张溪岸组件和六张水生植物逐图设定位置、尺寸和角度，不再使用统一数组批量套用同一规格；`stream-bank-08` 暂停使用。
4. 主路只在 `(1030,1040)` 的主倒木桥跨河，湿地探索支路只在 `(540,720)` 的次级倒木桥跨河。
5. 河流使用连续的水体阻挡链，桥面范围从阻挡链中留空。桥本身无阻挡，角色只能从桥面走廊通过。
6. 两座桥改为地表/桥面层，不再使用会与角色进行普通 Y-sort 的 `canopy` 层。
7. 雾瀑、湿地反光和两个出口界标单独布局；小地图仅保留可导航信息，不绘制雾、反光和装饰性水草。

## 3. 当前问题与根因

### 3.1 当前事实

- 地图尺寸为 `2048 x 2048`。
- 入口出生点约为 `(280,1700)`，部分1入口门户为 `(160,1840)`，部分3出口门户为 `(1880,260)`。
- 当前主路从西南向东北经过 `(1030,1040)`。
- 当前溪流使用一张中心约 `(1040,1040)`、角度 `28°`、尺寸 `2100 x 260` 的大水带。
- 当前 `ground-1` 与 `ground-2` 都是整图 tile，第二层以 `0.3` Alpha 同相位覆盖，容易出现重复纹理和规则网格；`ground-3` 没有明确用途。
- 当前 `2048 x 2048` 宏观遮罩以 `0.34` Alpha 整图覆盖，未避让出生点、桥头和出口，亮暗斑可能制造错误动线。
- 当前主路与湿地支路没有形成完整回路，湿地支路在次级桥附近结束，路径贴花、桥和河岸未按同一中心线校准。
- 十张溪岸组件统一显示为 `270 x 190`，但原始轮廓分别是弯道、封闭环、浅滩、支流口和竖向河段，不能使用相近角度和固定尺寸统一处理。
- 六张水生植物统一显示为 `120 x 120`、角度均为 `0°`，忽略了高瘦、横展、芦穗和灌木簇之间的轮廓差异。
- 当前 12 个水域碰撞体只覆盖若干岸边位置，没有形成连续水体阻挡，也没有将桥面定义为唯一缺口。
- 两座桥当前使用 `canopy` 深度角色，角色站上桥后可能出现桥体整体压住角色的问题。
- 当前湿地反光是一张 `1080 x 420` 的大图，容易形成矩形高亮底板，并与水带、岸线重复叠色。

### 3.2 根因

1. **视觉和地形结构不一致**：溪岸组件自身带有水面和河床，继续叠在大水带上会产生重复水色、接缝和局部堆叠。
2. **资产语义未分类**：`stream-bank-08` 是封闭环形构图，不适合直接拼进开放河流。
3. **碰撞表达错误**：零散岸边矩形只能制造局部空气墙，不能证明整条河流不可通行。
4. **桥面没有成为通行契约**：当前只是把桥图放在水面上，没有在水域阻挡链中建立与桥宽一致的通行缺口。
5. **路径和贴图分别设计**：主路、湿地支路、桥、溪流和岸线没有围绕同一交叉点共同校准。
6. **统一参数批量布局**：形态不同的溪岸和水草被强行使用同尺寸、同层级和近似角度，导致比例失真、互相穿插和视觉重心错位。
7. **整图叠层缺少职责边界**：地表变体、宏观遮罩、反光和水面都在大范围改变颜色，叠加后出现脏色、接缝和背景异常。

## 4. 不变量与非目标

### 4.1 必须成立

- 西南入口到东北出口始终存在连续主路，有效宽度不低于 `240px`。
- 河流除两座桥外全部不可通行，不设置可涉水浅滩。
- 主桥通行净宽不低于 `128px`；次级桥通行净宽不低于 `112px`。
- 入口、出生点和出口保持现有语义及至少 `220 x 220px` 净空。
- 水面、溪岸、水草、雾和反光均不承担物理碰撞。
- 物理阻挡由独立水体碰撞链负责，不能从贴图透明边界反推。
- 桥头前后各保留至少 `180px` 可站立净空，不摆水草、溪岸块或雾瀑。
- 部分2每张运行时纹理都必须在本方案中有明确的保留、移动、缩放、旋转、拆分或停用结论。
- 小地图必须能识别地图名、主路、连续河流、两座桥和两个出口，不显示雾、反光、水草或碰撞调试对象。

### 4.2 本轮不做

- 不新增游泳、涉水减速、跳跃或体力系统。
- 不引入多边形物理引擎。
- 不修改地图门户关系、任务、NPC、掉落或剧情状态。
- 不重画全部溪岸资产；确实不适合开放河流的组件先停用。

## 5. 优化后总体布局

```text
东北：前往部分3出口 (1880,260)
          │
          │ 主路北岸段
          ▼
     雾瀑背景区 (1710,390)
          │
======== 河流向东南流动 ========
              ╲
               ╲ 主倒木桥 (1030,1040)
                ╲
      湿地环路 ── 次级倒木桥 (540,720)
          ╲             ╱
           ╲           ╱
            主路南岸段
                 │
西南：部分1入口与出生点 (160,1840) / (280,1700)
```

### 5.1 主路控制点

```text
(280,1700) -> (500,1510) -> (710,1330) -> (870,1160)
-> (1030,1040) -> (1180,900) -> (1420,660)
-> (1650,430) -> (1840,260)
```

- `(870,1160) -> (1030,1040) -> (1180,900)` 必须与主桥长轴一致。
- 主桥前后 `220px` 内不摆大型溪岸块和水生植物。

### 5.2 湿地探索环路

```text
主路分叉 (710,1330) -> (560,1180) -> (470,960) -> (500,820)
-> 次级桥 (540,720) -> (700,640) -> (900,720)
-> 主路回接 (1180,900)
```

该支路从南岸跨到北岸，并在主桥之后重新接回主路，避免形成跨桥后无出口的死路。

### 5.3 溪流中心线

```text
(120,520) -> (360,650) -> (620,760) -> (900,930)
-> (1160,1110) -> (1430,1290) -> (1710,1450) -> (2020,1540)
```

溪流视觉宽度建议为 `220..250px`；碰撞阻挡带按 `210..230px` 控制，避免碰撞超出可见水面。

### 5.4 全量运行时资产审计矩阵

| 类别 | 纹理/对象 | 当前问题 | 优化动作 | 层级 | 碰撞 |
|---|---|---|---|---|---|
| 基础地表 | `ground-1` | 与第二层同相位时重复感明显 | 保留为唯一全图基础 tile | `underlay` | 无 |
| 地表变化 | `ground-2` | 整图 `0.3` 同相位覆盖，网格和拼接可见 | 相位偏移，Alpha 降至 `0.22` | `underlay` | 无 |
| 湿地变化 | `ground-3` | 当前无明确职责 | 仅作为局部湿地区域候选；无软边裁切时停用 | `underlay` | 无 |
| 宏观遮罩 | `part-2-macro` | 整图亮暗斑未避让关键动线 | 保留整图，锁定方向和锚点，Alpha 降至 `0.24` | `ground-decal` | 无 |
| 主路 | `forest-path-wet-soil-overlay` | 路径与桥、河流交叉未共同校准 | 按 5.1 控制点重建，宽 `260` | `ground-decal` | 无 |
| 湿地环路 | 同上 | 支路在桥边中断 | 按 5.2 闭环重建，宽 `190` | `ground-decal` | 无 |
| 水面 | `water-flow` | 单张大图旋转拉伸，接缝和背景异常 | 拆为 7 段，见第 6 节 | `ground-decal` | 无 |
| 溪岸 | `stream-bank-01..10` | 统一尺寸和近似角度导致交错 | 逐图显式布局，`08` 停用 | `ground-decal` | 无 |
| 水草 | `aquatic-foliage-01..06` | 统一 `120 x 120` 导致比例错乱 | 逐图显式尺寸、角度和岸侧 | `underlay` | 无 |
| 桥 | 两张 `fallen-log-bridge-*` | 整图参与 Y-sort，桥面遮角色 | 固定在角色下层，分别对齐两条路径 | `underlay` | 无 |
| 雾瀑 | `reverse-mist-fall` | 可能遮挡东北出口 | 保留上游背景区并限制可见范围 | `effect` | 无 |
| 反光 | `wetland-reflection` | 单张大矩形底板覆盖溪谷 | 拆为 4 个局部软边段 | `effect` | 无 |
| 出口界标 | `exit-left/right` | 容易被特效和装饰淹没 | 按门户动态绘制并保留净空 | `world` | 门户触发独立 |

不得继续通过“坐标数组 + 统一宽高”的方式生成 `p2Banks` 或 `p2Foliage`。每张贴图必须使用显式对象配置，以便独立校准尺寸、角度、Alpha、层级和小地图可见性。

### 5.5 地表整体重排

| ID | 覆盖范围/锚点 | 参数 | 规则 |
|---|---:|---|---|
| `p2-ground` | 全图 | tile，Alpha `1.0` | 唯一基础底色，不旋转、不缩放成单张大图 |
| `p2-ground-variant` | 全图 | tile，Alpha `0.22`，相位偏移约 `(384,256)` | 禁止与 `ground-1` 使用相同 tilePosition |
| `p2-ground-3` | 候选湿地区 `(480,1020)`、`(1300,1300)`、`(1720,1460)` | 局部 Alpha `0.14..0.18` | 仅在具有透明软边或遮罩时启用，否则首版停用 |
| `p2-macro` | 中心 `(1024,1024)`、`2048 x 2048` | Alpha `0.24`，角度 `0°` | 明亮区不得覆盖桥口、门户或出生安全区；不参与 ADD 混合 |

地表验收时必须单独关闭道路、水面和特效检查：看不到规则棋盘、重复亮斑、直线拼缝或大块异色背景，才允许继续叠加上层贴图。

### 5.6 道路贴图布局

- 主路按 5.1 的 9 个控制点铺设，宽度 `260px`、Alpha `0.74..0.78`。桥前后各 `140px` 逐步收窄至桥面净宽，但视觉泥土边缘不能延伸到水面。
- 湿地环路按 5.2 的 8 个控制点铺设，宽度 `190px`、Alpha `0.58..0.64`。次级桥前后路径中心必须穿过桥面中心，不得停在河岸贴图上。
- 两条道路只在 `(710,1330)` 与 `(1180,900)` 两处汇合，其他位置不得互相叠成大面积泥斑。
- 道路与水面相交部分由桥和桥下河床覆盖；禁止将道路贴花直接画在可见水面上制造“可涉水”暗示。
- 入口 `(280,1700)` 到第一个转折点之间保持至少 `280px` 的清晰引导带；东北出口前 `200px` 不摆高亮宏观斑或浓雾。

## 9. 河流不可通行方案

使用轴对齐短矩形沿溪流中心线覆盖整个水体，桥下不创建矩形。推荐首版参数：

| `p2-water-block-02` | `(335,635)` | `170 x 150` | 次级桥前 |
| `p2-water-block-03` | `(700,805)` | `160 x 150` | 次级桥后 |
| `p2-water-block-04` | `(825,875)` | `160 x 150` | 主桥前段 |
| `p2-water-block-05` | `(890,930)` | `140 x 140` | 主桥西北侧收口 |
| `p2-water-block-06` | `(1190,1130)` | `160 x 160` | 主桥东南侧起段 |
| `p2-water-block-07` | `(1310,1210)` | `170 x 160` | 中段 |
| `p2-water-block-08` | `(1440,1295)` | `170 x 160` | 中段 |

这些矩形需要在 `?debug-colliders=1` 下逐段检查。相邻矩形必须相交或边缘距离不超过角色碰撞直径的一半，避免斜向缝隙。

### 9.2 桥面缺口

- 次级桥缺口中心 `(540,720)`，沿溪流方向保留约 `210px` 空段。
- 主桥缺口中心 `(1030,1040)`，沿溪流方向保留约 `230px` 空段。
- 缺口宽度不得大于桥体可见通行面加两侧各 `18px` 容差。
- 桥两侧需要用相邻水体矩形收口，角色不能从桥边斜切进入水面。

### 9.3 禁止方式

- 禁止只在岸线上放几个不连续小矩形。
- 禁止给十张溪岸贴图各自配置通用碰撞体。
- 禁止用一张覆盖整条河流的大矩形空气墙。
- 禁止桥体自身承担阻挡，否则角色会被桥面挡住。

| 界标 | 门户中心 | 净空 | 布局规则 |

### 10.5 全图贴图间距与交错规则

- 桥头中心半径 `180px` 内禁止水草、溪岸主体、浓雾和反光高亮。
- 水草 Alpha 主体与道路可行走边缘至少间隔 `48px`。
- 相邻溪岸组件的 Alpha 主体重叠不得超过较小组件面积的 `20%`；不得出现三张岸块同时叠压。
- 水面段可重叠 `36..60px`，但高亮纹理不得同相位叠加形成亮线。
- 非出口贴图的可见主体距地图边缘至少 `32px`；大型特效距边缘至少 `48px`。
- 宏观遮罩、反光和雾瀑均不得侵入门户/出生安全区。
- 水面、岸线、道路和反光的交叉顺序固定为：基础地表 -> 道路 -> 水面 -> 溪岸/桥下河床 -> 桥主体 -> 反光/雾。
- 本区域没有普通 `world/canopy` 道具；不得把水草、岸线或整座桥临时改成 Y-sort 道具来修遮挡。

### 10.6 小地图表达

- 小地图显示当前地图名称 `微光森林·部分2：银雾溪谷`。
- 必须显示基础地表、主路、湿地环路、连续河流、两座桥、两个出口界标和玩家位置。
- 必须隐藏雾瀑、湿地反光、水生植物、碰撞调试矩形和装饰性 Alpha 边缘。
- 小地图中的河流必须连续，桥面必须形成两个清晰断点；不能因隐藏特效而把水面一并隐藏。
- 地图世界边界应贴合小地图可视区域，不出现底色之外的黑边；桌面与移动端分别检查标题不会挤压地图有效画面。

## 14. 对抗式审查

| 风险 | 真实用户影响 | 当前约束 |
|---|---|---|
| 水体矩形链有斜向缝隙 | 玩家从河岸角落钻进水中 | 相邻矩形重叠，按角色直径做采样测试 |
| 桥口留空过宽 | 玩家不走桥也能跨河 | 缺口宽度绑定桥面可见宽度 |
| 桥口留空过窄 | 玩家在桥头被无形墙卡住 | 桥中心线和两侧容差点均做自动测试 |
| 桥仍使用普通 Y-sort | 角色站桥时被整张桥图遮住 | 桥主体固定在角色下层 |
| 岸线组件重复水面 | 出现拼贴水池和明显接缝 | 岸线只作稀疏局部装饰，停用环形组件 |
| 水草靠近桥头 | 玩家误判桥面边界 | 桥头 `180px` 禁摆范围 |
| 小地图只显示水贴图不显示桥 | 玩家无法判断跨河点 | 两座桥必须保留在小地图静态层 |
| 地表变体与基础层同相位 | 全图出现规则重复和明显拼接 | 偏移 tilePosition 并降低第二层 Alpha |
| 宏观遮罩亮斑压住门户或桥头 | 玩家误判出口或道路方向 | 锁定锚点并避让三个安全区 |
| 水草继续统一尺寸 | 高瘦草被压扁、横展草挤入道路 | 六张逐图配置尺寸、角度和岸侧 |
| 大反光图仍覆盖溪谷 | 出现矩形底板和水色叠脏 | 拆成四段，先验证真实 Alpha |
| 小地图隐藏对象不完整 | 黑边、浓雾或装饰遮住导航信息 | 固定保留/隐藏清单并做双视口截图 |

完成定义不是“河流旁边有碰撞”，也不是“把几张错位贴图挪开”。完成时，部分2每张运行时纹理都有可追溯的布局结论，地表、道路、河流、岸线、植物、桥、特效、门户和小地图共同表达同一套空间结构；玩家在正常操作、斜向移动和桥边试探时都无法涉水，只能通过两座视觉清晰、方向正确的桥跨河。

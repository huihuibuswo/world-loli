# 微光森林地图与内部贴图优化规范 V1.0

> 文档状态：制作执行规范  
> 适用范围：微光森林俯视探索地图、地图内环境贴图、叙事节点和氛围特效  
> 剧情基准：《斗萝大陆_开局剧情设计_V2.0》及 S0 冷开场“月痕”已确认内容  
> 视觉参考：`S0_冷开场_月痕_缺失贴图生成提示词.md`、现有 `opening-s0-*` 演出资产  
> 本文不直接修改地图代码、服务端坐标或生成美术成品

## 1. 目标

将游戏内微光森林从“村庄草地换绿色滤镜”的通用森林，优化为能承接 S0 开场演出的标志性场景：

> 黄昏将尽的冷青森林中，树冠顺风摇动，贴地银雾却逆向流向西北深处；玩家沿被根系和湿苔切断的林径前进，最终抵达盘根古树、残缺月痕和月光空地共同构成的异常核心。

完成后的可玩地图必须同时满足：

1. 玩家一进入地图就能认出这是开场动画中的同一片微光森林。
2. 入口、主路、NPC、采集物、证据节点、露娜和回村出口均清晰可达。
3. 氛围神秘、压迫但不恐怖，不用可见怪物或血腥元素堆砌危险感。
4. 地图资产可分层、可循环、可降级，关闭动态效果后仍能正常游玩。

## 2. 权威信息与内容边界

### 2.1 必须保留的剧情视觉事实

| 剧情事实 | 地图中的可见表达 | 禁止误读 |
| --- | --- | --- |
| 场景位于微光森林深处，黄昏将尽 | 冷青蓝环境光、深绿植被、局部冷白微光 | 不能做成正午翠绿乐园或暖金童话森林 |
| 树梢风向与贴地雾流相反 | 树叶、落叶朝东或画面右侧偏移；低雾朝西北核心区流动 | 不能让树叶和雾同向运动 |
| 雾向古树根部聚拢 | 地表雾线、叶片伏倒方向和微光粒子共同指向核心古树 | 不能全地图均匀铺一层无方向雾 |
| 古树根部出现残缺月牙刻痕 | 核心古树根部设置唯一断月刻痕，低亮、分段、冷白 | 不能变成完整月亮、法阵或传送门 |
| 露娜肩侧负伤但仍在守护 | 月光空地预留露娜警戒站位，古树与狼族领地方向在她身后 | 不能把露娜放在无意义装饰角落或求救祭坛中央 |
| 威胁未直接现身 | 足迹中断、植物闭合、雾核、局部静音感和不自然空地 | 初次探索阶段不铺设大量可见怪物尸体或敌群 |

### 2.2 本文不提前解释的内容

- 不解释源萝之力的完整机制。
- 不揭示幕后污染者身份。
- 不把断月纹解释成常规魔法阵或自然月光祝福。
- 不新增幼崽、祭坛、献祭、墓地或其他未确认剧情元素。
- 不改变“露娜已经负伤、仍主动判断和守护”的角色立场。

## 3. 从开场 CG 到俯视地图的视觉翻译

开场 CG 是横向电影构图，游戏地图是 3/4 俯视探索视角。二者应共享视觉身份，但不能直接把 CG 背景当作地图底图。

| 演出语言 | 俯视地图翻译 | 实现重点 |
| --- | --- | --- |
| 远景幽深森林 | 地图边缘的高密度暗色树群、前景树冠和雾墙 | 边缘不可通行区比主路低 15%～25% 明度 |
| 古树位于画面偏右 | 古树作为西北月光空地的视觉重心，树冠可偏右上展开 | 树干交互区和角色站位不能被树冠遮住 |
| 银蓝雾横向逆流 | 沿主径和低洼区布置 2～3 条有方向的低位雾带 | 雾带宽窄变化，不能铺成整齐平行条纹 |
| 镜头推近刻痕 | 玩家沿路径逐步看见根系、微光裂纹、最后看见断月刻痕 | 利用明度和朝向引导，不依赖强制镜头也能成立 |
| 白光切黑 | 仅在剧情触发时作为局部演出特效 | 常态地图不持续高亮，不污染交互可读性 |

## 4. 当前实现差距审计

### 4.1 地图层面

当前 `WorldScene.ts` 的森林地图存在以下问题：

1. 森林和晨曦村共用 `grass-ground.webp`，仅叠加绿色蒙层，底色仍偏明亮、均匀和日间。
2. 森林和村庄共用 `dirt-path.webp` 及同一套路网，黄色宽路缺少林间湿土、根系侵入和雾区变化。
3. 主路线分叉来自村庄布局，没有围绕“东南入口 -> 森林向导 -> 三处异常 -> 西北月光空地”建立叙事递进。
4. 森林内十余处障碍重复使用同一张 `ancient-forest-tree.png`，核心古树因此失去唯一性。
5. 常态地图没有可识别的逆流雾、断月刻痕、雾核或狼族足迹环境表达。
6. 入口和传送点继续使用村庄路牌，视觉上更像郊外草地，不像进入森林边界。

### 4.2 现有资产层面

| 现有资产 | 当前问题 | 处置结论 |
| --- | --- | --- |
| `grass-ground.webp` | 高饱和翠绿、花朵密集、明度均匀，接近村庄草坪 | 森林停用；晨曦村保留 |
| `dirt-path.webp` | 暖黄、干燥、连续铺装感强 | 森林停用；新做冷湿林径纹理 |
| `ancient-forest-tree.png` | 圆润明亮、暖色树干、童话装饰感强，被大量重复 | 降级为开发占位；正式版重做普通树组和唯一核心古树 |
| `forest-obstacle.png` | 颜色偏暖、白花和红蘑菇抢眼 | 调冷降饱和后少量复用，并补 3～4 个轮廓变体 |
| `forest-stump.png` | 切面明亮、可爱装饰感明显 | 可复用为入口附近普通树桩；深处版本需增加湿腐、冷苔变体 |
| `opening-s0-reverse-mist-forest.png` | 横屏 CG 透视，不适合平铺和碰撞 | 只用作色彩、光照和氛围参考 |
| `opening-s0-reverse-mist-overlay.png` | 现有文件视觉上带黑底风险，且为横屏构图 | 不直接导入地图；重新输出透明、可循环的俯视雾带 |
| `opening-s0-broken-moon-mark.png` | 质感可参考，但视角、黑底和尺寸需处理 | 作为断月纹造型参考，地图版需重新生成或规范抠图 |
| `opening-s0-luna-wound-mist.png` | 属于角色局部演出特效 | 仅剧情演出复用，不作为环境常驻雾 |
| `opening-s0-white-flash-transition.png` | 属于一次性转场 | 仅剧情触发使用，不进入常态场景层 |

### 4.3 最需要修复的机制

问题的根因不是“森林贴图数量少”，而是地图没有视觉层级：普通树、核心古树、路径、异常节点和动态雾都在同一装饰权重上。

首版优化必须先建立以下层级，再增加细节：

```text
可读路径 < 普通森林结构 < 异常线索 < 核心古树与月光空地
```

## 5. 地图总体布局

### 5.1 坐标基准

- 世界边界：约 `2048 x 2048`。
- 东南为晨曦村入口与回村出口。
- 西北为月光空地、露娜和核心古树。
- 坐标原点位于左上，`x` 向右增加，`y` 向下增加。
- 本文保留当前服务端坐标作为兼容锚点；正式实现允许在不改变区域语义的前提下微调。

### 5.3 主路线

主路线应形成清晰但不笔直的“S”形递进：

1. 玩家从东南入口进入，先看到低密度树群和森林向导。
2. 经过向导后，暖色完全退出，林径变窄，第一次看见逆流薄雾。
3. 中部选择点可前往三条短支路：雾核湿地、狼族足迹开阔地、雾区边缘。
4. 三条支路都应能回接主径，避免调查后原路长距离折返。
5. 主径最终转向西北月光空地，核心古树在玩家接近前先露出树冠和根系，再露出刻痕。

### 5.4 路径可读性规则

- 可通行主路比周边地表亮 `8%～14%`，不依赖暖黄色区分。
- 使用被踩伏的草、裸露湿土、断根方向和稀疏雾线共同提示路线。
- 主路有效宽度建议不小于两个角色碰撞宽度加一段避让空间。
- 支路入口使用不同环境标志：湿地反光、断裂枝条、蓝白菌光或残石，不使用重复路牌。
- 不可通行边界由密集树干、盘根、岩石和浓雾共同构成，视觉边界应与物理碰撞一致。

## 6. 分区设计

### Z1 东南入口缓冲区

功能：地图传送、出生安全区、环境色过渡。

- 保留当前出生点 `(1800,1740)` 与回村口 `(1900,1840)` 的语义。
- 入口附近允许少量晨曦村方向的暖灰褐色，但进入 250～350 像素后必须过渡为冷青绿色。
- 使用“风化木界标 + 缠绕藤蔓 + 冷色提灯菌”替代通用村庄路牌。
- 雾量最低，路径最宽，不放大型前景遮挡和剧情证据。
- 回村传送圈应融入地表，不与断月纹共用同一种月牙造型。

### Z2 森林向导区

功能：玩家首次确认路线、建立森林安全边界。

- 保留森林向导约 `(1450,1420)` 的位置语义。
- 向导身后放置简易观察点、旧绳标或刻痕木桩，表达“有人维护到这里为止”。
- 从向导向西北看去，应能看到第一条逆流雾带，但看不到核心刻痕全貌。
- 银叶草节点 `(1600,1500)` 位于主路旁根系地，作为首次安全采集示范。

### Z3 雾核湿地

功能：断月雾核证据、后续雾痕兽影战斗、星砂薄荷采集。

- 以 `(1320,1180)` 为证据和战斗中心，外围保留 280～360 像素的可移动空间。
- 星砂薄荷 `(1280,1340)` 放在较低湿地，不与雾核交互光圈重叠。
- 地面使用冷湿泥、浅水反光和被吸向雾核的叶片，表现局部低洼。
- 雾核只在对应剧情阶段显示强响应；常态可保留低亮残留或空置凹坑。
- 战斗触发区上方不得覆盖大树冠；大面积透明雾最多使用一层中等浓度。

### Z4 雾区边缘

功能：表现森林深处不可预测性，承载雾绒蕨采集。

- 雾绒蕨节点 `(430,1330)` 位于古树下的半封闭小空地。
- 使用高低两层雾：低层指向西北，高层仅在边界缓慢漂移。
- 玩家可进入区域保持清晰，边界雾可更浓，但不能让可通行地面看起来被封死。
- 普通树干和盘根增加密度，树冠遮挡需在角色接近时降透明。

### Z5 狼族痕迹开阔地

功能：“突然中断的狼族足迹”证据，连接中部和月光空地。

- 证据锚点约 `(1010,890)`，地面应相对开阔，足迹从东南进入，在空地中央突然终止。
- 终止点周围不放跳跃石、断崖或水面，避免给玩家自然解释。
- 使用轻微压倒的草、泥印和朝向一致的断枝表达移动轨迹。
- 不出现狼尸、血泊或拖拽痕迹；异常来自“没有合理去向”。

### Z6 月光空地与核心古树

功能：S0 视觉回响、露娜首次交互与战斗、异常植物证据、地图视觉高潮。

- 露娜、月光百合和异常植物当前都以 `(620,520)` 为语义中心，正式布局必须拆开视觉站位。
- 建议核心古树树干中心位于空地北侧或东北侧，露娜位于树根前方，玩家从东南进入。
- 露娜与玩家之间预留战斗/对话空间；月光百合放在空地侧缘，不与 NPC 碰撞体重叠。
- “异常闭合的月光植物”应是一簇剧情对象，不直接把普通可采集月光百合当作同一个交互体。
- 古树根部断月刻痕面向玩家来路，常态低亮，剧情触发时才与银雾增强共鸣。
- 空地中央明度略高，但主光仍为冷白月色，不使用暖金圣光。
- 古树必须全图唯一；普通树不能使用相同树冠、树洞、月牙或发光根系设计。

### Z7 遗迹隐蔽区

功能：梦露花采集、非主线探索奖励、暗示森林历史但不解释主谜题。

- 梦露花节点 `(980,420)` 位于破损石墙或埋入树根的旧界碑附近。
- 遗迹符号采用抽象风化纹样，不复制断月纹，避免把两者误判为同源。
- 区域为短支路并回接月光空地外环，不做复杂迷宫。
- 奖励感来自构图和稀有植物，不使用宝箱、祭坛或强光柱。

## 7. 场景层级与组装规则

### 7.1 推荐层级

| 层级 | 内容 | 深度原则 |
| --- | --- | --- |
| L0 地表 | 冷湿腐殖土、苔藓、细碎落叶 | 固定底层，无碰撞 |
| L1 路径 | 湿土林径、浅水、伏倒植被 | 高于地表，不遮角色脚部 |
| L2 地表细节 | 小石、枝条、叶堆、菌类 | 无碰撞或极小碰撞 |
| L3 中景障碍 | 树干、树桩、岩石、盘根、遗迹 | 深度按脚点 `y` 排序 |
| L4 交互对象 | NPC、植物、证据、传送点 | 标签和光圈不得被雾遮挡 |
| L5 低位动态 | 逆流雾带、局部微光粒子 | 雾可穿过角色脚部，不盖住头脸 |
| L6 前景 | 树冠、近景枝叶、边界雾 | 接近角色时降透明或避开交互区 |
| L7 剧情特效 | 断月响应、伤口银雾、白光 | 只在剧情触发时启用 |

### 7.2 碰撞规则

- 树木碰撞只覆盖树干根部，不覆盖整张树冠画布。
- 树根若承担边界功能才设置碰撞；装饰性细根保持可跨越。
- 石块和树桩的物理范围应贴合底部轮廓，误差不超过视觉宽度的约 10%。
- 核心古树至少拆分“树冠显示范围”和“树干/主根碰撞范围”。
- 证据节点周围保留至少 72 像素交互净空；传送点周围保留至少 112 像素净空。
- 不允许透明空白区域阻挡角色，也不允许角色穿过明显实体树干。

### 7.3 遮挡规则

- 角色进入大型树冠下方时，遮挡层降至约 `35%～50%` 不透明度。
- NPC、证据节点、采集物和交互标签上方不放不可淡出的前景枝叶。
- 高浓度边界雾位于不可通行区域，不横跨主要交互点。
- 雾核和断月纹的发光半径不能覆盖附近对象标签。

### 7.4 光色规则

建议色彩基准：

| 用途 | 建议色相 | 明度关系 |
| --- | --- | --- |
| 森林暗部 | 深青绿、蓝黑绿 | 全图最低，但保留纹理 |
| 可通行地表 | 冷灰绿、湿土灰褐 | 比暗部高 8%～14% |

## 11. 动态效果与性能预算

### 11.1 雾

- 同屏建议最多 2 个大范围雾层和 1 个局部剧情雾层。
- 单层全屏平均不透明度建议控制在 `0.08～0.22`。
- 雾带循环周期建议 `12～24` 秒，避免快速烟雾造成视觉噪声。
- 雾流方向必须稳定，只有剧情响应时允许短暂加速或汇聚。
- 开启 `prefers-reduced-motion` 或低性能模式时，保留静态半透明雾贴花，停止位移动画。

### 11.2 粒子

- 常态同屏活动微光粒子建议 `20～32` 个。
- 月光空地或雾核剧情峰值可短时提高，但持续时间不超过必要演出段落。
- 普通区域不持续生成大型发光粒子。
- 粒子不承担导航信息，关闭粒子后路径和证据仍可识别。

### 11.3 纹理

- 常规单体优先控制在 `512x512` 以内。
- 核心古树、月光空地等唯一大型资产可使用 `1024x1024`，但应拆层并按需加载。
- 避免同时叠加多张 `1024x1024` 半透明图片覆盖整个镜头。
- 所有贴图导入前检查透明通道、空白边距、实际可见边界和压缩后边缘黑线。

## 12. 交互对象可读性

### 12.1 NPC

- 森林向导、训练教官和露娜周围保持清晰地面轮廓，不把角色放进高频叶片纹理中央。

2. 全地图动态树叶物理和复杂风场模拟。
3. 新增地图层级、洞穴、地下遗迹或大型迷宫。
4. 重做角色、NPC、战斗场景或开场视频。
5. 为每种植物制作完整生长动画。
6. 最终服务端坐标、碰撞数值和设备性能档位参数。

## 14. 对抗式审查

### Launch Blocker

| 风险 | 真实影响 | 上线前要求 |
| --- | --- | --- |
| 继续复用暖黄道路和明亮草坪 | 开场与可玩地图像两个不同地点 | 必须换成森林专属地表与路径 |
| 核心古树贴图重复铺满全图 | 叙事标志失去唯一性 | 普通树和核心古树必须拆分 |
| 露娜、月光百合、异常证据重叠 | NPC、采集和剧情交互互相遮挡 | 必须拆开视觉站位和净空 |
| 雾层黑底或伪透明 | 游戏画面出现黑块、边缘黑线 | 导入前验证真实 Alpha 通道 |
| 树冠整图参与碰撞 | 玩家被透明区域卡住 | 碰撞只贴合树干和粗根 |
| 浓雾遮住路径或交互标签 | 玩家误判不可通行区域 | 高浓度雾限制在边界和剧情区 |
| 后续证据在首次入林时全部可见 | 提前泄露月痕追迹调查内容，削弱阶段推进 | 证据、标签和雾痕兽影按剧情阶段显隐 |

### Follow-up

- 普通树变体不足导致重复感。
- 遗迹和湿地细节不够丰富。
- 低端设备雾层降级过于明显。
- 静态地图中树冠顺风方向表达较弱。

这些问题影响完成度，但在 Must 项已经成立时不阻断首版地图上线。

## 15. 联合验收清单

### 剧情验收

- [ ] 第一眼能识别冷青黄昏、逆流雾、核心古树和残缺月痕。
- [ ] 树冠/落叶方向与低位雾流方向相反。
- [ ] 露娜站位体现她守在古树与狼族领地方向之间。
- [ ] 地图没有提前解释幕后者、源萝之力或完整月痕机制。
- [ ] 未加入可见怪物、血腥或祭坛来替代环境异常叙事。

### 地图与玩法验收

- [ ] 从东南入口可自然找到森林向导和西北月光空地。
- [ ] 三处证据和五个采集点都有清晰环境归属与可达路径。
- [ ] 所有调查支路能回接主径或控制在短距离折返范围。
- [ ] 露娜、月光百合和异常植物的显示、碰撞与交互区域互不覆盖。
- [ ] 回村出口清晰可见，但不与断月纹共享视觉符号。

### 美术验收

- [ ] 普通树至少 5 个明显变体，核心古树全图唯一。
- [ ] 森林地表和路径不存在明显无缝接缝或棋盘重复。
- [ ] 抠图素材是真透明或能稳定抠除的纯色背景，没有黑底残留。
- [ ] 地图贴图统一为 3/4 俯视视角，没有混入正视 CG 资产。
- [ ] 冷色背景下角色、NPC、植物和证据仍保持清晰轮廓。

### 技术验收

- [ ] 树干、树根、石块和树桩碰撞与可见实体基本一致。
- [ ] 前景树冠不会永久遮挡角色和交互标签。
- [ ] 关闭雾动画和粒子后，路径、边界和证据仍可读。
- [ ] 同屏透明大图和粒子数量符合性能预算。
- [ ] 小地图、任务追踪和交互 UI 不受雾层遮挡。

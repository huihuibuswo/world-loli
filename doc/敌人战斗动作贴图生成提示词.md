# 敌人战斗动作贴图生成提示词

## 1. 交付方式

不需要生成透明背景。所有图片统一使用纯洋红色背景：

```text
#FF00FF
```

生成后不要自行抠图、加阴影或压缩为 JPG。保留 PNG 原图，我会负责：

1. 去除洋红色背景。
2. 按网格切成独立帧。
3. 对齐角色中心和脚底基线。
4. 缩放并组装为项目使用的 1024 × 1280 透明 PNG。

每名敌人生成一张动作表，共 6 张：

```text
npc-village-chief-combat-sheet-source.png
npc-shopkeeper-combat-sheet-source.png
npc-suna-combat-sheet-source.png
npc-forest-guide-combat-sheet-source.png
npc-trainer-combat-sheet-source.png
npc-luna-combat-sheet-source.png
```

生成每名角色时，请上传对应的现有角色图片作为参考图。

### 1.1 带图生成建议

每次只上传一名角色的原图，并生成该角色的一张动作表，不要同时上传多名角色。

如果生成工具提供参数，建议使用：

| 参数 | 建议 |
| --- | --- |
| 参考图/角色一致性 | 高或最高 |
| 图生图强度/重绘幅度 | 30%～45% |
| 风格强度 | 低到中，优先保持原图画风 |
| 创意程度 | 低 |
| 输出数量 | 每次 1 张，检查后再重试 |
| 输出格式 | PNG |
| 背景 | 纯 `#FF00FF` |

操作顺序：

1. 上传对应角色原图。
2. 粘贴第 3 节通用提示词。
3. 把“角色要求”替换成第 4 节对应角色描述。
4. 在提示词开头追加下面这段身份锁定语句：

```text
上传图片是角色身份源图，不是普通风格参考。动作表中的每一帧必须保持源图角色的脸、发型、发色、服装结构、配饰、武器和身体比例。只允许改变动作、姿势和表情，禁止重新设计角色。
```

5. 生成后优先检查脸、发型、服装和武器，再检查动作和网格。

如果工具支持“角色参考”和“风格参考”两个入口，把原图放入角色参考；不要只放入风格参考。

## 2. 网格与动作顺序

目标是严格的 4 列 × 5 行，共 20 个方形格子：

| 行 | 动作 | 第 1～4 帧 |
| --- | --- | --- |
| 1 | attack | 蓄力、起手、命中、收招 |
| 2 | defense | 警觉、抬手防御、稳定格挡、恢复 |
| 3 | hit | 正常、后仰、最强受击、恢复 |
| 4 | death | 失衡、倒下、落地、最终倒地姿势 |
| 5 | victory | 准备、庆祝起势、庆祝高潮、胜利定格 |

建议输出：

- 首选尺寸：1024 × 1280。
- 如果工具不支持该尺寸，选择接近 4:5 的竖图。
- 每格角色大小、镜头距离和脚底位置必须一致。
- 每格四周保留约 10% 空白，身体、武器、头发和特效不能被裁切。

## 3. 通用提示词

把下面提示词中的“角色要求”替换为第 4 节对应角色内容，并上传该角色原图。

```text
用途：2D 游戏战斗角色动作表。

参考图：上传图片是唯一角色身份参考。必须严格保留参考图中的脸型、发型、发色、服装、鞋子、武器、配饰、身体比例、主色和可爱日系 Q 版画风。所有格子必须是同一个角色，禁止换装、改变年龄或改变画风。

角色要求：
【粘贴对应角色描述】

生成一张严格的 4 列 × 5 行战斗动作表，共 20 个大小完全相同的正方形格子。不要绘制格子边框和分隔线。

第一行 attack，从左到右：
1. 战斗蓄力和准备姿势；
2. 攻击起手，身体和武器开始运动；
3. 攻击命中动作最强的一帧；
4. 收招并准备回到待机。

第二行 defense，从左到右：
1. 察觉攻击并收紧重心；
2. 抬起武器或双臂进行防御；
3. 稳定的原地格挡姿势，身体前方出现小型青色半透明魔法护盾；
4. 护盾减弱并恢复站姿。

第三行 hit，从左到右：
1. 受到攻击前的正常姿势；
2. 身体向后轻微受击；
3. 最明显的受击后仰表情和姿势；
4. 重新站稳。受击动作不掉落或改变装备。

第四行 death，从左到右：
1. 体力不支、身体失去平衡；
2. 开始向侧后方倒下；
3. 身体落地；
4. 保持安静的最终倒地姿势，适合画面停留。不要出现血液或伤口。

第五行 victory，从左到右：
1. 意识到胜利；
2. 开始角色化庆祝动作；
3. 胜利动作最明显的一帧；
4. 自信、可爱且适合停留的胜利姿势。

构图要求：
- 每格都显示完整全身，固定正面略微朝向画面左侧的 3/4 视角。
- 所有帧保持完全一致的角色尺寸、头身比、镜头高度和脚底基线。
- 每格角色独立，不得跨格、重叠或出现额外角色。
- 动作变化必须清晰，但不能把角色画成不同的人。
- 攻击命中固定在第一行第三格。
- 防御护盾最强固定在第二行第三格。
- 倒地最终姿势固定在第四行第四格。
- 胜利定格固定在第五行第四格。

背景要求：
整张图片除角色、武器和动作特效外，背景必须是完全均匀的纯色 #FF00FF。背景不能有渐变、纹理、地面、投影、接触阴影、反光、烟雾、景物、光斑、网格线或颜色变化。角色和背景边缘清晰。角色、服装、武器和特效中禁止使用 #FF00FF。

风格：高质量可爱日系 Q 版游戏角色贴图，细节清楚，柔和描边，颜色和参考图一致。

禁止内容：文字、数字、水印、Logo、动作名称、格子编号、边框、额外肢体、重复武器、缺失手指、身体裁切、角色换装、不同脸型、不同发型、写实画风、黑色背景。
```

## 5. 如果整张 4 × 5 网格生成失败

图像模型常见问题包括：格子数量不对、动作串行错位、角色跨格或不同帧换装。出现这些问题时，
不要反复要求模型修整张图，改为每个动作单独生成一张 4 帧横条。

把通用提示词中的动作部分替换为下面模板，每名角色生成 5 张：

```text
生成一张严格的 4 列 × 1 行横向动作条，共 4 个大小完全相同的正方形格子。不要绘制格子边框。

动作名称：【attack / defense / hit / death / victory】
四帧内容：【粘贴第 2 节对应动作的四帧说明】

四格必须是同一个角色，角色大小、镜头、脚底基线、服装、发型、武器和颜色完全一致。每格完整显示全身并保留 10% 空白，不得跨格或裁切。

整张图片除角色、武器和特效外，背景必须是完全均匀的纯色 #FF00FF。禁止渐变、纹理、地面、阴影、反光、网格线、文字、编号和水印。
```

分行动作文件建议命名：

```text
npc-suna-attack-source.png
npc-suna-defense-source.png
npc-suna-hit-source.png
npc-suna-death-source.png
npc-suna-victory-source.png
```

其余角色替换文件名前缀即可。收到 5 条动作图后，我会负责拼接成项目需要的完整动作表。

## 6. 生成后检查

每张图片至少确认：

- [ ] 正好 4 列 × 5 行，或单行动作图正好 4 列 × 1 行。
- [ ] 20 帧/4 帧都是同一个角色，没有换装或改变发型。
- [ ] 角色和武器没有被裁切。
- [ ] 背景只有纯 `#FF00FF`，没有阴影、渐变和网格线。
- [ ] 攻击、防御、受击、倒地和胜利动作能明显区分。
- [ ] 防御动作是原地格挡，不是攻击动作。
- [ ] 第四行最后一帧可以作为稳定的倒地停留帧。
- [ ] 图片为 PNG，不是 JPG。

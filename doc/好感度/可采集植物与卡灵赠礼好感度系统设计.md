# 可采集植物与卡灵赠礼好感度系统设计

## 1. 目标

玩家在世界地图中发现并采集植物，将植物作为礼物赠送给已拥有的卡灵，从而提升对应卡灵的好感度，并形成以下循环：

> 探索地图 → 发现植物 → 采集并进入背包 → 查看卡灵偏好 → 赠送植物 → 提升好感度

本阶段只设计植物采集与赠礼好感度，不包含种植、炼金、交易、烹饪和植物战斗技能。

## 2. 名词约定

- 玩家界面可以使用“卡牌角色好感度”的通俗说法。
- 数据层的好感度属于玩家拥有的卡灵实例，即 `player_card_spirits.affection`。
- 普通战斗卡牌本身不单独保存好感度；由某个卡灵提供的卡牌，共享该卡灵的好感度加成。
- 好感度范围保持现有规则：`0～100`。

### 稀有度视觉

- 普通：绿色微光，不在小地图上显示。
- 少见：蓝色微光，靠近一定范围后显示在小地图上。
- 稀有：金色微光，并带有清晰的植物名称标牌。

颜色只用于辅助识别，采集提示中必须同时显示植物名称和稀有度文字。

## 4. 地图采集规则

### 4.1 交互

- 植物作为地图对象存在，类型为 `collectible_plant`。
- 玩家进入植物交互范围后显示：`E 采集「植物名」`。
- 键盘按 `E`、点击交互提示或使用移动端互动按钮都能采集。
- 采集期间锁定角色移动，播放约 `600ms` 的采集反馈后获得物品。
- 采集成功后显示：`获得 植物名 ×1`。

### 4.2 刷新

- 每个采集点独立记录刷新时间。
- 同一采集点被采集后暂时隐藏，到达刷新时间后重新出现。
- 服务端决定能否采集，客户端不能仅通过重新加载地图重复获得植物。
- 单次采集默认获得 1 个；未来若有采集技能，再扩展额外产量。

### 4.3 背包

- 植物进入现有 `inventories` 背包体系，`item_type` 使用 `plant`。
- 同类植物允许堆叠，默认最大堆叠数量为 `99`。
- 背包达到上限时不消耗采集点，并提示玩家先整理背包。

## 5. 赠礼与好感度

### 5.1 基础规则

1. 玩家只能向自己已拥有的卡灵赠送植物。
2. 每次赠送消耗背包中的 1 个植物。
3. 好感度增加值由植物基础值和卡灵偏好共同决定。
4. 好感度达到 100 后不可继续赠送，植物也不会被消耗。
5. 赠礼不会降低好感度；不喜欢的植物仍至少增加 1 点，避免玩家误操作后完全损失物品。

计算公式：

```text
实际好感度 = min(100 - 当前好感度, max(1, 植物基础好感度 + 偏好加成))
```

| 偏好关系 | 加成 | 反馈文案 |
|---|---:|---|
| 最喜欢 | +2 | “这是她最喜欢的礼物！” |
| 喜欢 | +1 | “她看起来很喜欢这份礼物。” |
| 普通 | +0 | “她收下了你的礼物。” |
| 不喜欢 | 结果固定为 +1 | “她礼貌地收下了礼物，似乎不太合口味。” |

单次最多增加 `6` 点好感度。

### 5.2 卡灵偏好示例

当前 Demo 卡灵“狼娘·露娜”的偏好：

| 关系 | 植物或标签 |
|---|---|
| 最喜欢 | 月光百合、`月光` |
| 喜欢 | 银叶草、星砂薄荷、`清凉` |
| 普通 | 晨露草、阳铃花、雾绒蕨、梦露花 |
| 不喜欢 | 火绒花、`辛香` |

后续新增卡灵时，每个卡灵至少配置：

- 1 个最喜欢标签；
- 1～2 个喜欢标签；
- 0～1 个不喜欢标签；
- 一句收到最喜欢礼物时的专属对白。

### 5.3 频率限制

- 同一卡灵每天最多接受 5 次植物赠礼。
- 连续赠送相同植物时不追加额外奖励，但正常计算好感度。
- 赠礼次数按 `Asia/Shanghai` 自然日重置，数据库时间仍统一存储为 UTC。
- 赠礼不与现有 60 秒普通互动冷却共用，避免对话后无法立即赠礼。

## 6. 好感度阶段与效果

沿用现有阶段划分：

| 好感度 | 阶段 | 现有效果 | 建议表现 |
|---:|---|---|---|
| 0 | 初识 | 无伤害加成 | 基础对话 |
| 1～20 | 初识 | 卡灵来源卡牌伤害 +5% | 基础对话 |
| 21～50 | 熟悉 | 卡灵来源卡牌伤害 +10% | 解锁一段日常对白 |
| 51～80 | 信赖 | 卡灵来源卡牌伤害 +20% | 解锁专属赠礼反应 |
| 81～100 | 羁绊 | 卡灵来源卡牌伤害 +30% | 解锁最终羁绊对白 |

赠礼只负责提升好感度，不直接增加玩家属性、卡牌等级或卡灵经验。

## 7. 数据设计建议

### 7.1 植物模板 `plant_templates`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | bigint | 植物模板 ID |
| `name` | varchar(128) | 唯一名称 |
| `rarity` | varchar(32) | `common`、`uncommon`、`rare` |
| `base_affection` | integer | 基础好感度，范围 1～4 |
| `tags` | jsonb | 礼物标签数组 |
| `description` | text | 背包描述 |
| `icon` | text | 图标资源路径 |
| `respawn_seconds` | integer | 刷新秒数 |

### 7.2 采集状态 `player_plant_nodes`

| 字段 | 类型 | 说明 |
|---|---|---|
| `player_id` | bigint | 玩家 ID |
| `map_id` | bigint | 地图 ID |
| `node_id` | varchar(64) | 地图内稳定采集点 ID |
| `plant_template_id` | bigint | 植物模板 ID |
| `available_at` | timestamptz | 下次可采集时间 |

建议使用 `(player_id, map_id, node_id)` 作为唯一键，让不同玩家拥有独立采集进度。

### 7.3 卡灵偏好 `spirit_gift_preferences`

| 字段 | 类型 | 说明 |
|---|---|---|
| `spirit_template_id` | bigint | 卡灵模板 ID |
| `plant_template_id` | bigint，可空 | 指定植物偏好 |
| `tag` | varchar(32)，可空 | 标签偏好 |
| `preference` | varchar(16) | `favorite`、`liked`、`disliked` |
| `dialogue` | text，可空 | 专属收礼对白 |

植物与标签同时命中时，只取最高等级偏好，不叠加奖励。

### 7.4 赠礼记录 `spirit_gift_records`

记录玩家、卡灵、植物、增加的好感度和赠送时间，用于每日次数限制、问题追踪和后续成就统计。

## 8. API 建议

### 获取当前地图植物状态

```http
GET /api/v1/map/{map_id}/plants
```

返回植物位置、稀有度和当前是否可采集。

### 采集植物

```http
POST /api/v1/plants/collect
```

```json
{
  "map_id": 2,
  "node_id": "forest_moon_lily_01"
}
```

服务端校验玩家地图、采集点状态和刷新时间，并原子增加背包数量。

### 向卡灵赠送植物

```http
POST /api/v1/spirits/{spirit_id}/gifts
```

```json
{
  "plant_template_id": 8
}
```

成功响应至少返回：

```json
{
  "spirit_id": 1,
  "plant_template_id": 8,
  "preference": "favorite",
  "affection_gained": 6,
  "affection": 42,
  "remaining_amount": 2,
  "dialogue": "这朵花……有和月光一样安心的味道。"
}
```

背包扣除、好感度增加和赠礼记录必须在同一个数据库事务中完成。

## 9. 前端交互

### 地图

- 可采集植物拥有轻微轮廓光和名称标签。
- 靠近后复用现有互动提示与移动端互动按钮。
- 请求期间禁用重复采集，并显示采集进度反馈。

### 背包

- 新增“植物”分类，显示图标、数量、稀有度、标签和描述。
- 已进入刷新状态的地图植物不应继续显示可采集提示。

### 卡灵详情

- 新增“赠送植物”按钮，打开玩家当前拥有的植物列表。
- 默认把最喜欢和喜欢的植物排在前面，但不直接隐藏偏好关系。
- 赠送成功后显示卡灵立绘、专属对白、好感度增量和进度条变化。
- 空背包、达到每日上限、好感度已满和网络失败都必须给出明确反馈。

## 10. 与当前代码的差距

当前项目已经具备：

- `inventories` 通用背包表；
- `player_card_spirits.affection` 卡灵好感度；
- `gift` 好感度来源类型；
- 好感度对卡灵来源卡牌的伤害加成。

仍需实现：

1. 植物模板、采集点状态、卡灵偏好和赠礼记录表；
2. 地图植物对象与采集 API；
3. 指定植物的赠礼 API及原子扣除；
4. 植物背包与卡灵赠礼界面；
5. 将当前固定 `gift +3` 改为本文档的植物基础值与偏好计算。

## 11. 最小验收标准

- 晨曦村和微光森林都至少存在 3 种可采集植物。
- 玩家靠近植物后可按 `E` 采集，成功后背包数量增加。
- 刷新时间内不能重复采集同一采集点。
- 玩家可以从卡灵详情选择并赠送背包中的植物。
- 赠送后植物数量准确减 1，好感度按偏好准确增加且不超过 100。
- 好感度已满、植物不足、每日次数用尽或并发重复请求时不会错误扣除物品。
- 重新登录后，背包、采集刷新时间、赠礼次数和好感度保持一致。

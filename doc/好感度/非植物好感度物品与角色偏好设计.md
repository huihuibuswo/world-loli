# 非植物好感度物品与角色偏好设计

## 1. 设计目标

在现有植物赠礼之外，增加食物、书籍、工艺品、矿物、纪念品等好感度物品，让礼物选择能够体现 NPC、卡灵与魔物娘的人设，而不是只比较物品稀有度。

核心循环扩展为：

> 探索、战斗、任务或商店获取礼物 → 根据角色人设判断偏好 → 赠送礼物 → 获得角色化反馈与好感度

本设计优先解决以下问题：

- 非自然系角色缺少符合人设的礼物；
- 同一件高稀有度礼物不应对所有角色都是最优解；
- 礼物来源需要覆盖探索、战斗、商店和任务；
- NPC 与可收集卡灵应使用同一套礼物标签语言。

本阶段不实现烹饪、锻造、炼金、礼物合成、随机词条和玩家间交易。

## 2. 通用规则

### 2.1 礼物分类

| 分类 | 说明 | 主要来源 |
|---|---|---|
| 食物 | 肉干、甜点、果冻、茶饮等可消耗礼物 | 杂货商、任务、怪物掉落 |
| 书籍 | 故事书、研究笔记、地图册、训练记录 | 任务、遗迹、NPC 商店 |
| 工艺品 | 铃铛、护符、音乐盒、锻造工具等 | 商店、任务奖励、后续制造 |
| 矿物 | 水晶、矿石、珍珠、遗迹碎片 | 矿洞、湖区、战斗掉落 |
| 纪念品 | 徽章、旧物、羽饰、照片等剧情物品 | 角色任务、探索事件 |

### 2.2 稀有度与基础好感度

| 稀有度 | 基础好感度 | 定位 |
|---|---:|---|
| 普通 `common` | +1 | 可稳定购买或重复获得 |
| 少见 `uncommon` | +2 | 区域探索、普通任务或战斗掉落 |
| 稀有 `rare` | +4 | 隐藏探索、角色任务或低概率掉落 |
| 剧情 `story` | +4 | 与特定角色经历相关，不按价格衡量 |

继续沿用现有偏好加成：

```text
实际好感度 = min(100 - 当前好感度, max(1, 基础好感度 + 偏好加成))
```

| 偏好 | 加成 | 规则 |
|---|---:|---|
| 最喜欢 `favorite` | +2 | 命中角色核心欲望、记忆或身份 |
| 喜欢 `liked` | +1 | 符合兴趣、生活习惯或能力属性 |
| 普通 `neutral` | +0 | 愿意收下，但没有特殊触动 |
| 不喜欢 `disliked` | 最终固定 +1 | 与性格、经历或身体特性冲突 |

单次好感度仍不超过 `6`。礼物价格、稀有度与偏好分别计算，避免“贵重等于喜欢”。

### 2.3 标签原则

礼物使用可复用标签匹配角色偏好。建议首批标签控制在以下范围：

`肉食`、`甜点`、`辛香`、`清凉`、`温暖`、`果冻`、`茶饮`、`知识`、`魔法`、`故事`、`冒险`、`训练`、`音乐`、`手工`、`锻造`、`矿物`、`水域`、`月光`、`古代`、`纪念`、`安静`、`实用`、`闪亮`、`拟态`、`守护`、`锋利`、`污染`

指定物品偏好优先于标签偏好，同一次赠礼只取最高等级，不叠加。

## 4. 卡灵与魔物娘偏好

### 4.1 DR001 狼娘·露娜

人设依据：活泼、忠诚、喜欢冒险；偏爱肉类、月光与能证明共同经历的物品。

- 最喜欢：月盐肉脯、银月小铃；标签 `肉食`、`月光`
- 喜欢：香烤肉干、旅行者地图册、指北羽饰；标签 `冒险`
- 不喜欢：标签 `辛香`、过于浓烈的火焰气味
- 专属对白：“是月盐的味道！下次出发时，也把我算进队伍里吧。”

### 4.2 DR002 树妖娘·莉莉

人设依据：温柔、安静、擅长照顾生命；重视自然节律和体贴心意。

- 最喜欢：木纹音乐盒、手编守护结；标签 `安静`、`手工`
- 喜欢：晨曦暖茶、净音风铃、回声贝壳
- 不喜欢：黑曜护片、熔纹锻造锤；标签 `锋利`、`污染`
- 专属对白：“这段旋律很像古树醒来时的声音……谢谢你记得我喜欢安静。”

### 4.3 DR003 小魔女·艾米

人设依据：傲娇、聪明、热爱研究；喜欢有研究价值的魔法资料和精致甜点。

- 最喜欢：失落术式残页、星糖曲奇；标签 `魔法`、`知识`
- 喜欢：初级魔法习题集、星纹晶核、古代文字拓片
- 不喜欢：实战训练记录册、粗糙或没有原理说明的工具
- 专属对白：“我只是对术式感兴趣，才不是因为你特意替我找来的……残页先借我研究。”

### 4.4 DR004 史莱姆娘·米露

人设依据：天真、好奇、喜欢模仿；偏爱有弹性、会变化或颜色鲜明的东西。

- 最喜欢：彩虹拟态冻、软云抱枕；标签 `果冻`、`拟态`
- 喜欢：弹弹果冻、星糖曲奇、透光水晶；标签 `闪亮`
- 不喜欢：精工磨刀石、黑曜护片；标签 `尖锐`
- 专属对白：“它会变颜色！米露也会！你看，你看，变得一模一样啦！”

### 4.5 DR005 矿石娘·诺雅

人设依据：认真、坚强、可靠；欣赏结构稳定、材质优秀和真正实用的礼物。

- 最喜欢：星纹晶核、黑曜护片；标签 `矿物`
- 喜欢：精工磨刀石、熔纹锻造锤、透光水晶；标签 `实用`、`锻造`
- 不喜欢：软云抱枕、易碎且只有装饰用途的物品
- 专属对白：“晶体没有暗裂，结构也很稳定。你挑选它时一定很认真。”

### 4.6 DR006 人鱼娘·菲娜

人设依据：优雅、温柔、神秘；喜欢水域珍物、音乐与细腻的情感表达。

- 最喜欢：湖心珍珠、回声贝壳；标签 `水域`、`音乐`
- 喜欢：净音风铃、月下冒险故事集、晨曦暖茶
- 不喜欢：熔纹锻造锤、带焦烟气味的物品
- 专属对白：“它保存着湖水的回声。今晚，我会为你唱一首与它相配的歌。”

### 4.7 DR007 幽灵娘·幽幽

人设依据：害羞、孤独、喜欢故事；渴望被记住，也害怕突然的强光和噪声。

- 最喜欢：无名少女的日记、记忆琥珀；标签 `故事`、`纪念`
- 喜欢：月下冒险故事集、木纹音乐盒、古代文字拓片；标签 `安静`
- 不喜欢：声音尖锐的铃铛、过亮的发光饰品
- 专属对白：“她的故事没有写完……我可以和你一起，替她记住后面的事吗？”

### 4.8 DR008 铁匠少女·苏娜

人设依据：热情、直率、喜欢创造；重视工具质量、材料特性和实际行动。

- 最喜欢：熔纹锻造锤、星纹晶核；标签 `锻造`
- 喜欢：精工磨刀石、黑曜护片、实战训练记录册；标签 `手工`、`实用`
- 不喜欢：脆弱、华而不实且妨碍工作的饰品
- 专属对白：“重量、导热和握感都正好。好材料不能闲着，等我把它变成真正有用的东西。”

### 4.9 DR009 森林祭司少女·伊芙

人设依据：温柔、虔诚、善良；重视守护、疗愈、生命记忆和真诚心意。

- 最喜欢：手编守护结、净音风铃；标签 `守护`、`温暖`
- 喜欢：晨曦暖茶、木纹音乐盒、记忆琥珀；标签 `安静`、`纪念`
- 不喜欢：带有掠夺象征或明显破坏自然痕迹的物品
- 专属对白：“贵重的不是材料，而是你编进结里的祝愿。我会好好守护它。”

### 4.10 DR010 古代守护少女·瑟琳

人设依据：冷静、神秘、智慧；关注古代文明、源萝之力和被遗忘的历史。

- 最喜欢：源萝刻印碎片、古代文字拓片；标签 `古代`
- 喜欢：失落术式残页、记忆琥珀、星纹晶核；标签 `知识`、`魔法`
- 不喜欢：缺乏来历的一次性消费品、刻意仿造的“古董”
- 专属对白：“这枚刻印不属于现存纪年。你带来的不是礼物，而是一段仍在呼吸的历史。”

## 6. 获取与区域投放建议

### 6.1 晨曦村首批可落地物品

为控制首轮实现规模，建议先上线以下 12 件：

1. 香烤肉干
2. 蜂蜜烤饼
3. 弹弹果冻
4. 晨曦暖茶
5. 旅行者地图册
6. 实战训练记录册
7. 银月小铃
8. 精工磨刀石
9. 指北羽饰
10. 软云抱枕
11. 透光水晶
12. 商队纪念币

来源分配：

- 杂货商常驻出售：香烤肉干、蜂蜜烤饼、弹弹果冻、晨曦暖茶、软云抱枕；
- 铁匠铺出售或任务奖励：精工磨刀石、透光水晶；
- 森林向导任务：旅行者地图册、指北羽饰；
- 训练教官挑战：实战训练记录册；
- 村长或商队事件：商队纪念币；
- 狼娘·露娜相关事件：银月小铃。

## 7. 数据结构扩展建议

当前系统以 `plant_templates` 和 `spirit_gift_preferences.plant_template_id` 为中心。为支持非植物礼物，建议后续统一为通用物品模型，不继续为食物、书籍、矿物分别建立赠礼表。

### 7.1 礼物模板

建议新增 `gift_item_templates`：

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | bigint | 礼物模板 ID |
| `name` | varchar(128) | 唯一名称 |
| `category` | varchar(32) | `food`、`book`、`craft`、`mineral`、`memento` |
| `rarity` | varchar(32) | `common`、`uncommon`、`rare`、`story` |
| `base_affection` | integer | 基础好感度 1、2 或 4 |
| `tags` | jsonb | 礼物标签数组 |
| `description` | text | 背包描述 |
| `icon` | text | 图标路径 |
| `sell_price` | integer，可空 | 剧情礼物可禁止出售 |

现有植物可继续保留采集模板，但在赠礼时投影为统一结构：

```json
{
  "gift_type": "plant",
  "gift_template_id": 8,
  "base_affection": 4,
  "tags": ["月光", "花朵"]
}
```

### 7.2 偏好与赠礼目标

将偏好抽象为：

```text
character_gift_preferences
- target_type: spirit | npc
- target_template_id
- gift_type: plant | item
- gift_template_id: 可空
- tag: 可空
- preference
- dialogue: 可空
```

赠礼记录增加 `target_type`，但植物与非植物必须复用同一套每日次数、事务扣除和并发保护。

## 8. 前端表现建议

- 卡灵详情中的“赠送植物”改为“赠送礼物”；
- 背包增加“礼物”分类，植物仍可保留独立采集分类；
- 礼物选择列表显示分类图标、稀有度、标签、持有数量与角色偏好；
- 未发现的偏好默认显示“未知”，避免在初次见面时直接公开完整答案；
- 角色收下最喜欢或不喜欢的礼物时，必须显示人设化专属对白；
- 剧情礼物增加“重要物品”标记，赠送前二次确认；
- 好感度已满、今日次数用尽、目标未解锁赠礼、物品不足时不得扣除物品。

## 9. 最小验收标准

- 首批至少有 12 件非植物礼物，覆盖 5 类中的至少 4 类；
- 狼娘·露娜和晨曦村 5 名 NPC 均配置最喜欢、喜欢和不喜欢的礼物或标签；
- 同一件礼物对不同角色可以产生不同偏好结果；
- 最喜欢礼物能触发角色专属对白；
- 植物与非植物礼物遵循同一好感度上限、每日次数和原子扣除规则；
- 稀有礼物若不符合人设，不会自动优于普通但命中最喜欢的礼物；
- 剧情礼物不可误出售，赠送前有明确确认；
- 重新登录后，物品数量、赠礼记录和好感度保持一致。

## 10. 延后内容

以下内容暂不进入首批实现：

- 烹饪和食谱；
- 锻造或礼物制造；
- 礼物品质、随机词条和耐久度；
- NPC 之间互相赠礼；
- 节日限定礼物和生日系统；
- 玩家交易与礼物市场；
- 赠礼失败、好感度下降或永久错过剧情。

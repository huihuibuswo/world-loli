# 可采集植物贴图生成提示词

## 统一生成规格

- 用途：Phaser 世界地图中的可采集植物，也可缩放后用于背包图标。
- 画布：`512 × 512 px`，PNG，透明背景，正方形画布。
- 构图：单株或小型自然株丛，完整入镜，主体居中略偏下，根部落在画布下半部中央，四周保留约 12% 透明空间。
- 视角：约 45° 斜俯视，与项目现有树桩、森林石块和房屋贴图一致。
- 风格：温暖治愈的日系奇幻 2D 游戏地图物件，精致手绘赛璐璐上色，圆润清晰轮廓，柔和明暗，细节丰富但在缩小到 `64～80 px` 时仍能辨认。
- 光照：左上方柔和暖光，轻微环境遮蔽；允许植物自身具有微弱发光特征，但不生成稀有度光圈。
- 边缘：干净锐利，无白边、黑边和锯齿，适合透明贴图直接叠加。
- 输出目录：`game-client/public/assets/generated/sprites/plants/`

## 生成与验收建议

1. 每种植物先生成 2～4 个候选，只选择轮廓最清楚的一张。
2. 在 `512 px` 原图确认透明边缘干净，再缩小到 `64～80 px` 检查辨识度。
3. 如果缩小后细节糊成一团，应减少叶片和小花数量，不要单纯提高锐化。
4. 所有图片应保持相同视角、左上光源和根部基准线，避免放进地图后出现倾斜或漂浮感。
5. 普通、少见、稀有的绿色、蓝色、金色光圈由 Phaser 运行时绘制，不写入植物原图。
6. 贴图不得自带文字、底板、完整地面阴影或方形背景。

生成后按文件清单命名，并放入：

```text
game-client/public/assets/generated/sprites/plants/
```
